# Support us

Source: https://docs.nestjs.com/support

Nest 是一个 MIT-获得许可的开放源码项目，其持续开发得益于社区的支持。这个框架是漫长的不眠之夜、**下班后**的工作和繁忙的周末的结果。

#### 你能帮上什么忙？

Nest 没有一家大公司的支持，该公司不断为其开发花费的时间付费。我完全依赖**善**❤️社区的。我很想让这个框架变得更好，并完全专注于提供让编码变得愉快的解决方案。为了实现这一点，我运行了几个支持平台：

- 成为支持者或赞助商 [OpenCollective](https://opencollective.com/nest)
- 发送一次性捐款 [PayPal](https://paypal.me/kamilmysliwiec)
- 或直接联系我 [mail@kamilmysliwiec.com](mailto:mail@kamilmysliwiec.com)

如果你爱 Nest，或者你的企业使用它，考虑赞助它的开发，以确保你的产品所依赖的项目得到**积极维护**和改进。您的支持也帮助我为整体创建更多内容 Nest 社区，如教育博客帖子和视频。
